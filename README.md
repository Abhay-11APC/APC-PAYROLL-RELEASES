# APC Payroll — installers

Installers only (no source code, no data). The APC Payroll app on each PC checks this place at start and every 4 hours
and installs a newer version by itself when it is closed — only if the release is signed with APC's private key.

- Current version: **2.15.4** — `Vetan-Payroll-Setup-2.15.4.exe`
- Previous version (manual fall-back): **2.15.3** — `Vetan-Payroll-Setup-2.15.3.exe`
- SHA-256 of the current installer: `a31ea621c5b4207921ff3e7cb1fd77e15cfd8d27d8492db385197aa7045cba1a`

To install on a new PC (or repair one): download **`APC-Payroll-App-Online-Setup.exe`** (small) and run it — it downloads,
checks and installs the current version. Or download the current installer above and run it.
