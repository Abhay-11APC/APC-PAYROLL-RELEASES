# APC Payroll — installers

Installers only (no source code, no data). The APC Payroll app on each PC checks this place at start and every 4 hours
and installs a newer version by itself when it is closed — only if the release is signed with APC's private key.

- Current version: **2.9.6** — `Vetan-Payroll-Setup-2.9.6.exe`
- Previous version (manual fall-back): **2.9.5** — `Vetan-Payroll-Setup-2.9.5.exe`
- SHA-256 of the current installer: `9a15f813710c0e8630c5103de53601150aa4d1ff917889d5d6cbb754b3b501d6`

To install by hand on a new PC: download the current installer and run it.
